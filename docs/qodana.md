# Qodana scanning (retired)

Qodana scanning is no longer configured in this repository. On 2026-10-27,
`.github/workflows/qodana.yml` and `qodana.yaml` were removed. Pushes,
pull requests and manual workflow dispatches no longer start a Qodana scan.

This page remains because older review notes link here. Those notes describe
the former setup and are historical; this is not a runbook for a current scan.
See the [PR review record](renewal/2026-10-19-pr-review-fixes.md) for the
original findings and decisions.
